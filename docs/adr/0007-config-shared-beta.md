# 配置级唯一 beta

状态：已接受，取代 ADR 0006 的按规则独立内容模型。

## 背景

同一配置需要一个稳定的灰度编辑目标。按规则保存正文会产生多份 beta，规则数量影响内容数量，并要求用户理解规则与编辑目标的关系。

## 决定

每份配置最多一份无编号的 beta；所有有序规则命中它。第一条规则创建时选择保留主版本复制，之后直接覆盖 beta，不记录编辑历史。历史列表顶部展示 beta 编辑入口。关闭全部规则保留 beta，删除最后一条规则删除 beta。回退仅对主版本生效；beta 转全量保留规则与 beta。

## 后果

规则只表达匹配范围，编辑目标固定且无需来源编号。无法为不同规则设置不同正文，这是有意收窄的需求。HTTP/WebSocket 用 beta 标识及 version=0 表达无编号内容；服务端和 SDK 同步升级。schema 4 不兼容旧数据，按用户确认使用空数据库重建，不尝试合并旧 beta 或自动删除用户数据。
