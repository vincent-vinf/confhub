# 管理认证采用纯 JWT

第一版只有单个 admin 账户，用户选择使用简单的纯 JWT，避免数据库会话表及请求级会话查询。令牌默认有效 2 小时、无刷新令牌，通过 HttpOnly Cookie 携带，各实例共享启动参数或环境变量中的签名密钥；退出只清除浏览器令牌，密码修改不自动撤销已经签发的令牌。这是简化服务状态与即时撤销能力之间的明确取舍。

后续多用户功能由 [0008-users-and-scoped-permissions.md](0008-users-and-scoped-permissions.md) 扩展：仍使用 JWT 且无会话表，每次请求查询用户状态/授权，改密和启停账号通过认证版本撤销旧 JWT。
