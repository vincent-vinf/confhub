# 多用户及范围授权

增加多用户后，管理权限按 namespace/group 授予只读或读写，写包含读，默认拒绝，多条授权取并集。系统管理员管理用户和组织；初始化 admin 始终保留管理员身份。在线客户端及标签共享连接上下文，采用单独的全局 clients.read 权限。

当前模型使用集中式权限检查，无自定义角色、继承、拒绝规则或单份配置授权，暂不引入 Casbin。后端独立检查全部入口，列表过滤范围，批量操作检查所有来源和目标，匹配模拟归入只读操作。

扩展 [0005](0005-stateless-admin-jwt.md)：仍使用 JWT Cookie，无会话表。JWT 携带用户 ID 和 auth_version，每次管理请求在数据库事务中读取用户及授权的一致快照。权限变更在各实例下一次请求生效；密码修改、重置和启停账号递增 auth_version，旧令牌失效。代价是每个管理请求增加用户/授权查询；客户端读取和通知不受此开销影响。

schema 5 使用 migrate 从 schema 4 复制 admin 密码摘要，不修改配置模型。启动仍不隐式升级已有数据库，需显式执行迁移并重启所有实例。旧 admin 令牌不再接受。客户端 HTTP GET/WebSocket 仍无需鉴权，这次范围权限只约束控制台和管理 API。

详细协议见 [users-permissions.md](../users-permissions.md)。
