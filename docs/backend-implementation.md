# 后端实现记录

范围依据 [requirements.md](requirements.md)、[architecture.md](architecture.md) 与五份 ADR。此阶段实现 Go 服务端及必要的单元、集成测试，不实现 React 页面、客户端 SDK 或压测流程。

## 实现顺序

1. PostgreSQL/MySQL 迁移、启动参数与领域类型。
2. 通过真实数据库的保存/读取测试实现事务存储，再逐项实现版本、乐观锁、灰度与回退。
3. 实现格式校验、组织管理、历史引用与短期租约清理。
4. 实现 Gin 管理 API、单 admin 初始化、JWT Cookie 与同源校验。
5. 实现 WebSocket 多配置订阅、广播消费、有界缓存、背压、故障补偿和健康状态。
6. 提供命令行、Docker/Compose、协议文档；运行完整测试和代码审查，修复发现的问题后提交。

## 已确认的测试边界

- 配置管理/灰度解析公共接口：版本、目标、回退、格式与乐观锁行为。
- 真实 PostgreSQL 存储公共接口：事务、迁移、持久日志和清理行为。MySQL 保留产品支持，此阶段按用户要求不运行其集成测试。
- HTTP/WebSocket 公共协议：认证、跨实例推送、订阅恢复、删除及同名重建。

接口测试检查调用者可观察的行为，不 mock 内部方法，不依赖内部表查询来判断成功。故障注入仅在数据库等外部边界进行。

## 当前状态

后端业务存储、管理认证/API、WebSocket、同步消费与后台维护已实现，逐项测试正在完成。Docker 镜像已构建，Compose 配置已校验；最终代码审查及完整测试尚待完成。性能和资源指标仍未验证。
