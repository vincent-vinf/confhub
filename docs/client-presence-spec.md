# IP 区间与在线客户端

本次用户需求：新增 IP 段匹配；灰度标签名自动补全，并能查看标签值；新增只读客户端页面，展示连接、订阅版本和标签；规则填写时建议标签值。

- 新增 `ip_range`，`values` 为起止两个完整 IP，包含端点；按地址数值比较，支持 IPv4/IPv6，同族、无 zone，拒绝反向或无效区间。标签仍可自定义，默认建议 `sys.ip`。表单使用明确的起止输入，不使用缩写地址。
- 在线指成功升级且尚未关闭的 WebSocket 连接。HTTP GET 不记录为在线。每次连接有独立 ID，展示连接实例、远端地址、连接时间、标签和订阅。
- 每个订阅展示服务器成功发送的版本、规则 ID、配置 ID/修订号、删除状态；不宣称客户端应用已确认，不采集配置正文。未发送的订阅显示等待发送。
- 多实例共用数据库临时连接记录，每 5 秒同步，实例心跳采用数据库时钟，20 秒过期；正常断连下次同步移除，进程异常退出过期移除，后台清理过期数据。只有连接信息有最终一致性，配置通知链路不依赖此功能。
- 客户端页面仅供管理员只读查看，分页，每页 25 条；展示自动刷新、最近读取时间与延迟说明，支持刷新、空态、加载和错误态。
- 标签建议来自所有有效实例的在线客户端，而非当前页面；名称始终包括 `sys.ip` 和 `sys.hostname`。按输入前缀查询，最多 100 条去重建议。建议不限制自由输入，以便为暂未上线的客户端配置规则。标签值仅用于建议，保持字符串值语义。
- PostgreSQL 与 MySQL 均提供迁移。schema 2 可显式迁移至 3；不改变已有配置、灰度、客户端协议或 SDK。schema 1 仍拒绝迁移。
- 沿用已批准的三类测试边界：配置/灰度公共接口、真实 PostgreSQL 存储接口、HTTP/WebSocket 公共协议。界面沿用现有设计体系、响应式和键盘交互。

审查补充：合法 JSON 标签字符串（包括 Unicode、NUL 和尾部空格）不能导致整个实例 heartbeat 写入失败；标签索引使用二进制字段以保留字节语义。键盘选择长建议列表时，活动项应始终在弹出列表可见区域内。
