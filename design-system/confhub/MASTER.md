# ConfHub 控制台设计系统

使用 ui-ux-pro-max 检索了开发者工具与企业管理台。已验证 Minimalism & Swiss Style 适用于本产品；检索的营销页面结构不适用于内部管理台，因此不采用该结构，以下布局是针对既有需求的设计判断。

- 产品：桌面优先的配置管理工具；默认中文，保留 Namespace/Group 和格式名称等熟悉术语。
- 风格：深色固定导航、浅色内容工作区、细分隔线、紧凑数据表、低装饰。提供完整深色主题；不使用虚构的统计或在线客户数。
- 配色：绿色主操作（light #14745c，dark #83ddc0）；中性蓝灰导航与表面。状态均配文字，禁用、错误和焦点具有独立语义。
- 字体：自托管 IBM Plex Sans（正文）与 JetBrains Mono（配置、版本和业务名称）；中文使用系统无衬线字体。正文 14–16px，标题 24–28px。
- 间距：4/8px 网格，页面 24/32px，控件高度至少 40px，触屏至少 44px。最多 25 行分页，避免无限列表。
- 布局：左侧产品与导航，顶部面包屑及主题/账号入口，主体包含标题、Namespace/Group 筛选、内容卡片。375/768/1024/1440px 响应式，窄屏导航抽屉、编辑工具栏换行，diff 窄屏纵向排列。
- 交互：可见键盘焦点、表单标签、就近错误、异步按钮防重复提交、模态焦点管理/Escape/取消、离开草稿提示、登录过期保留编辑、减少动态效果。
- 代码编辑：CodeMirror 6、按需格式扩展；原文和格式化可撤销。仅保存确认及历史比较使用只读 diff。
- 发布确认：默认比较当前编辑目标（全量或规则目标），可换历史版本但不得改变乐观锁基准；展示影响范围并要求勾选确认。冲突保留草稿、读取最新状态后再次比较。

具体流程和验证证据写入 docs/frontend-implementation.md；语义 token 集中于 frontend/src/styles.css。
